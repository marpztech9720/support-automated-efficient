# ChromeTechnology Customer Support App

A modern customer support application built with React, TypeScript, and Vite. This application provides a user-friendly interface for submitting support tickets, an admin dashboard for managing tickets, and a rating system for feedback collection.

## Features

- Customer support form with file uploads
- Admin dashboard with password protection
- Rating system for feedback collection
- Glassmorphism UI design
- Responsive layout for all device sizes
- ChromeTechnology branding

## 🚀 Deployment Options

### Option 1: GitHub Pages (Setup Complete)

The project is already configured for GitHub Pages deployment. Follow these steps:

1. Push your code to GitHub
2. Run the deployment command:
   ```bash
   npm run deploy
   ```
3. Your site will be available at: `https://[your-github-username].github.io/support-automated-efficient/`

### Option 2: Vercel (Recommended for Production)

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your GitHub repository
4. Deploy automatically

### Option 3: Netlify

1. Push your code to GitHub
2. Go to [netlify.com](https://netlify.com)
3. Connect your GitHub repository
4. Deploy with build command: `npm run build`
